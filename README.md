# Banking Transaction Interface

A core banking transaction and ledger interface built with HTML, Tailwind CSS, and JavaScript.

## Features Implemented
1. **Create Bank Account**: Create customer profiles with unique IDs and opening balances.
2. **Deposit Funds**: Real-time deposit credit and audit ledger tracking.
3. **Withdraw Funds**: Liquidity verification, overdraft protection, and safe debiting.
4. **Transfer Funds**: Inter-account atomic transfers with simultaneous sender debit and recipient credit.
5. **Delete Dormant Account**: Safeguards preventing active accounts, accounts with positive balances, or accounts with active loans from deletion.
6. **Bonus - Loan Facility Disbursal**: Instant creation of loan contracts and immediate 10,000 KES disbursal into target account balance.
